Entry for [news-image-20261125](https://make.fun/bounty/news-image-20261125):
sum up Wednesday 25 November 2026's world news in one image. The date
"25 November 2026" appears in the masthead and again in the footer, so the
image names the day it sums up.

  Tiangong station.

## How it works

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` (960x960) to `$MAKEFUN_OUTPUT_DIR/entry.png` (default
`/output/entry.png`). No network, no third-party packages, so it runs
cleanly in the grader's stock Python image. Two runs produce byte-identical
output (verified locally with `python3 -P -s`, fresh output dirs).
